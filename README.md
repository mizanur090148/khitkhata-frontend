# KnitKhata Frontend (শিল্পসেতু)

Modern Single-Page Application (SPA) for **KnitKhata (শিল্পসেতু)** — Subcontract Knitting Factory & Vendor Management Platform.

## 🚀 Tech Stack
- **React 18** + **TypeScript**
- **Vite 6**
- **React Router 6**
- **Responsive Silk UI**

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Setup
Configure your API URL in `.env`:
```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
```

### 3. Development Server
```bash
npm run dev
```

### 4. Production Build
```bash
npm run build
```
The compiled static assets will be output to `dist/`.
